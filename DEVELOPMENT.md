# H.I.V.E. - Technische Dokumentation

## System-Setup
- Engine: Godot 4.x
- Editor: VS Code (External)
- Terminal: WSL Ubuntu
- Koordinatensystem: Axial (q, r) umgewandelt in Cube (q, r, s)

## Konventionen
- Type-Safety: Strikte Typisierung mit `:=` oder `: Type`
- Architektur: Signal-basiert (Observer Pattern)
- Dokumentation: ## für Klassen, # für Logik-Kommentare

## Aktuelle Struktur
- /scenes: UI und Testumgebungen
- /scripts: Logik-Komponente
- /resources: HexData Ressourcen
